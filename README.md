A Python project that securely hides secret messages inside images using **Fernet encryption** and **SHA-256 hashing**.  
This ensures that messages are not only hidden but also **encrypted**, providing maximum confidentiality.

---

## 📌 Project Overview

This project allows users to:

- **Encrypt a secret message** using Fernet (symmetric encryption)  
- **Hash the message** using SHA-256 for integrity  
- **Hide the encrypted message inside an image** using steganography techniques  
- **Retrieve and decrypt the message** only with the correct key  

This ensures **both confidentiality and integrity** of the hidden message.

---

## 🎯 Objectives

- Securely hide secret messages in images

- Ensure message integrity with SHA-256

## ⚙️ Features

- 🔒 Encrypt messages using **Fernet**  
- 🛡️ Verify message integrity using **SHA-256 hash**  
- 📷 Hide messages inside images (PNG, JPG)  
- ⚡ Fast encoding and decoding  
- 🖥️ Simple Python
